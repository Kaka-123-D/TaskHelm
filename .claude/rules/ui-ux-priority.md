# UI/UX Development Priority

When working on any UI/UX task (components, pages, layouts, dashboards, styling, responsive design):

1. **ALWAYS use the `ui-ux-pro-max` plugin** as the primary tool for generating and reviewing UI code
2. Use `frontend-design` plugin as secondary support
3. Follow the design system and style guide from ui-ux-pro-max output
4. Do NOT generate UI code manually without first consulting ui-ux-pro-max

This applies to:
- Web dashboard screens (Project List, Task Board, Task Cockpit)
- CLI output formatting and table layouts
- Any component, page, or layout work
- Design system and theme setup
